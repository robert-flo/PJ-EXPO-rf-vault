# 03.0 - Expo Simulators (MOC)

Simuladores iOS/Android en la nube construidos para agentes de código: [expo.dev/services/simulators](https://expo.dev/services/simulators). Lanzados el 12 de nov de 2026, disponibles en planes pagos. Sesiones aisladas, evidencia (screenshots, logs) para PRs, skill `eas-simulator`, soporte de Appium/Maestro vía agent-device.

Aquí entra el Android del programa (emuladores cloud), y el iOS sin Mac.
