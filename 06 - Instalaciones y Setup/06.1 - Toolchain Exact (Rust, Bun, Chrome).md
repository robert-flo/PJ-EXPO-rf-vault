# 06.1 - Toolchain Exact (Rust, Bun, Chrome)

> @ref LLP 0000#overview — alcance web + host Linux, sin Mac

## Qué instalar (según README de exact, ruta Linux)
- **Rust** vía rustup; la toolchain fija en `rust-toolchain.toml` se instala sola al primer `cargo run`.
- **Bun 1.4.2** (la versión que fija `package.json` de exact). Node y npm no se necesitan.
- **Google Chrome**: el agente maneja la web con Chrome headless. Otro Chromium con `CHROME=`.
- No aplica: Xcode (no hay Mac); en Linux el host nativo y el loop web sí corren.

## Verificar e instalar (`make doctor`)

El vault es el punto de convergencia. `make doctor` es auto-sanador: primero informa qué está OK y qué falta (curl, unzip, git, gh, chromium, compilador C, rustup, rust 1.97.0, bun, checkout de exact, gh autenticado); después RESUELVE lo que puede solo: los paquetes de pacman con sudo, rustup y bun con sus instaladores oficiales, el checkout de `expo/exact` clonado en `proyectos/exact` (o el que apunte `$EXACT`), y el `setup` de exact dentro del checkout. Termina con TODO LISTO (exit 0) o con la lista de pendientes (exit 1): se vuelve a correr `make doctor` hasta que diga TODO LISTO. Lo único que requiere de ti es la contraseña de sudo cuando toca instalar paquetes, y `gh auth login` si gh no está autenticado. Corre `make doctor` desde el vault, en tu terminal.

```
git clone https://github.com/expo/exact
cd exact
bun scripts/exact.mjs setup
bun scripts/exact.mjs new ~/ruta/de/la/app
```
