# 08.1 - Skills de LLP (instalación)

El usuario no usa Claude Code: las skills de LLP se copian a mano y cualquier agente las consume vía el bloque de ruteo en `AGENTS.md` (lo que upstream documenta como válido).

## Instalación manual (upstream)
```
git clone --branch v0.5.2 --depth 1 https://github.com/ccheever/llp
cp -r llp/skills/<skill> <carpeta-de-skills-del-agente>/
```

## El set core
| Skill | Qué hace |
| --- | --- |
| llp-orient | carga el contexto LLP que gobierna una tarea (read-only) |
| llp-create | autor un LLP nuevo con número y scaffold |
| llp-review | loop de revisión LLP 0005 escalado por riesgos |
| llp-adopt | traer LLP a un repo o paquete (greenfield o retrofit) |
| llp-maintain | drift, reparación de refs, curaduría (propone, no aplica) |

Opcionales: `llp-super-refine` (review-plus), `llp-ship` (delivery).
