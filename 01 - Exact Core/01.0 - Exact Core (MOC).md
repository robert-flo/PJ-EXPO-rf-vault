# 01.0 - Exact Core (MOC)

Base principal del programa: [expo/exact](https://github.com/expo/exact). Runtime multiplataforma: se escribe la UI en **Contract** (DSL declarativo) y la lógica en TypeScript o Rust; corre en web, macOS, iOS y Linux. Pre-1.0, cambia a diario, sin API estable.

## Tres principios (del README upstream)
1. **Agent native**: un agente construye, corre, ve y prueba la app. Diez operaciones (`tree`, `screenshot`, `tap`, `type`, `state`, `layout`, `logs`, `clock`, `prefer`, `perf`) vía `scripts/agent.mjs`.
2. **Speed is king**: cold start 100 ms, edición a la página en ~100 ms.
3. **Write the web, ship the platform**: escribes CSS, el resto lo aporta cada plataforma.
